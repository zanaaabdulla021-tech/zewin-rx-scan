# iOS setup

Add these keys inside `ios/Runner/Info.plist`, once you generate the iOS
project with `flutter create .`:

```xml
<key>NSCameraUsageDescription</key>
<string>پێویستە کامێرا بەکاربهێنرێت بۆ وێنەگرتنی ڕەسیت</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>پێویستە وێنەکان بەکاربهێنرێت بۆ هەڵبژاردنی وێنەی ڕەسیت</string>
```
